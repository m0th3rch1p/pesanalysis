# Backend contract suite (scaffold)

One suite, any backend (D44). Inputs: an `InferenceBackend` (and optionally `EmbeddingBackend`). Checks: planner exact-match and execution accuracy, constrained-JSON schema validity, narration number verification, latency/throughput, peak RAM, injection red-team, and `assertAllowed`. Output: dated row in `docs/eval-latest.md` + JSON artefact. See docs/POST_HACKATHON.md section 2.
